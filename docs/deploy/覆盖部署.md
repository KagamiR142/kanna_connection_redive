# 覆盖部署（zip 升级）

## 数据在哪里

当前版本（v2）**统一使用** `resource/data/`（见 `basedata.FilePath`）：

| 路径 | 内容 | 部署时 |
|------|------|--------|
| `resource/data/setting_clanbattle.json` | 主配置（管理员 QQ、API 密钥、过码等） | **勿覆盖** |
| `resource/data/data.db` | SQLite（账号、绑定、预约/申请/挂树、刀型预算等） | **勿覆盖** |
| `resource/data/token.json` | 过码 token 缓存 | **勿覆盖** |
| `resource/data/rungroup.json` | 监控群映射 | **勿覆盖** |
| `resource/data/boss_info.json` | Boss 元数据（可 `刷新会战元数据` 更新） | 建议保留服务器副本 |
| `resource/data/web_ops_log.jsonl` | Web 运维日志 | **勿覆盖** |
| `resource/data/temp/` | 临时查询缓存 | 可忽略 |
| `resource/data/setting_clanbattle.example.json` | 配置模板 | 可随代码更新 |
| `resource/data/rank_exp.csv` | 静态表 | 可随代码更新 |
| `resource/img/` | Boss 图标等（运行时会缓存） | 一般可覆盖 |
| `resource/font/` | 状态图字体 | 随代码更新 |

模块根目录下的 `data/`（若存在）为**旧版或遗留路径**，`.gitignore` 已排除；新部署以 `resource/data/` 为准。

账号与成员数据在 **SQLite `data.db`** 内，不再依赖散落的 `account/*.json`（v1 迁移见 `database/migrate.py`）。

## 打包

**Windows（推荐，开发机完成 Web 构建，服务器无需 npm）：**

```bat
scripts\pack_deploy.bat
```

仅更新 Python 后端、未改 Web 时：

```bat
scripts\pack_deploy.bat --skip-web
```

**跨平台 / 手动：**

```bash
cd web && npm ci && npm run build && cd ..
python scripts/pack_deploy.py --with-web-dist
# 或仅后端
python scripts/pack_deploy.py
```

产物默认在 `dist/kcr-deploy-<时间戳>.zip`。zip **不包含**配置与数据库；**默认 bat 会打入 `web/dist/`**，解压后覆盖服务器上的前端静态文件。

## 服务器覆盖

```bash
# 1. 停 bot
# 2. 备份（强烈建议）
cp resource/data/setting_clanbattle.json resource/data/setting_clanbattle.json.bak
cp resource/data/data.db resource/data/data.db.bak

# 3. 解压到模块目录（覆盖代码）
unzip -o kcr-deploy-*.zip -d /path/to/HoshinoBot-master/hoshino/modules/kanna_connection_redive/

# 4. 若使用 pack_deploy.bat 打包，已含 web/dist，无需在服务器构建

# 5. 启动 bot
```

因 zip 内没有 `setting_clanbattle.json` / `data.db`，解压**不会**删除或覆盖服务器上已有文件。
