# 安装与部署指南

面向在 **HoshinoBot + go-cqhttp（或兼容协议端）** 环境部署自动报刀与 Web 面板。

---

## 架构概览

| 组件 | 说明 |
|------|------|
| **HoshinoBot** | 加载 `kanna_connection_redive`：QQ 指令、监控、SQLite |
| **协议端** | 群消息、私聊、图片、群信息 API |
| **会战 Web API** | 模块内 FastAPI，Bot 启动时独立线程监听 |
| **会战 Web 前端** | `web/` 构建为静态资源，Nginx 或 API 托管 |

数据流：

- 群聊 **出刀监控** → 约 1 秒/轮 `top` + `reload_detail_info`，Boss 以 top 为准
- **状态** → DTO + `status_image` PNG
- Web 面板 → `/kanna_dependency/{group_id}/panel`；状态图 → `/status-image`

---

## 环境要求

- **Python**：与 HoshinoBot 一致；模块需 Pillow、httpx、FastAPI、uvicorn、SQLAlchemy 等
- **字体**：`resource/font` 勿删（状态图依赖）
- **网络**：游戏 API、Boss 头像 CDN、可选 satroki 拉取 `boss_info.json`
- **磁盘**：SQLite 与图标缓存写在 `data/`、`resource/img/`（`.gitignore`，首次自动创建）

## 安装步骤

### 1. 放置模块

```
HoshinoBot-master/hoshino/modules/kanna_connection_redive/
```

在 Hoshino 配置中启用模块（与其它 `hoshino/modules` 相同）。

### 2. 会战配置

```bash
cd hoshino/modules/kanna_connection_redive/resource/data
cp setting_clanbattle.example.json setting_clanbattle.json
```

编辑 `setting_clanbattle.json`（**勿提交 Git**）。`admin_qq`、`api.admin_key`、`web_admin` 密码等须改掉示例占位符；`api.admin_key` **无**长度上下限，仅要求非空。更完整的「必填 / 建议改 / 不必动 / 不在 JSON 维护」说明见仓库 **README**「Web 会战面板 → 超级管理员如何配置」。

启动时 `clanbattle_setting.ensure_config_or_exit()` 校验配置，失败则拒绝启动。

### 3. 启动 Bot

1. 启动协议端（go-cqhttp / Lagrange 等）
2. 启动 Hoshino：`python run.py`
3. 日志应出现：`KCR Web API 已启动 host=... port=...`

### 4. 绑定与开监控

1. 管理员 **私聊** 绑定 **出刀监控账号**（`绑定账号帮助`；与成员 Web 身份无关）
2. 目标群发送 `出刀监控`
3. 发送 `状态` 应收到 PNG（失败时回退文本）

成员私聊 `注册` 后登录 Web，在「个人数据」绑定游戏 UID（或由管理员代绑）；群聊 `绑定本群公会` 加入 Web 公会列表。

## Web 前端部署

### 构建

仓库已包含预构建的 **`web/dist/`**，部署可直接挂载，**无需**本机 `npm run build`。

若你修改了 `web/src/`，在模块内重新构建：

```bash
cd hoshino/modules/kanna_connection_redive/web
npm ci
# 可选 .env：VITE_API_BASE=/kanna_dependency
npm run build
```

产物覆盖 `web/dist/`（可提交以便他人免构建）。

### 托管（二选一）

**A. Nginx 反代（推荐）**

- `/kanna_dependency` → `http://127.0.0.1:8138`
- 其余 → `web/dist/index.html`（SPA）
- SSE：`/kanna_dependency/{group_id}/panel/stream` 需 `proxy_buffering off`

**B. FastAPI 挂载静态目录**

见 `web/说明.md` 中 `StaticFiles` 示例。

## 运维检查清单

| 检查项 | 期望 |
|--------|------|
| `setting_clanbattle.json` 存在 | `admin_qq` 正确 |
| 群监控 `loop_check` 活跃 | Boss HP 自动刷新 |
| `resource/data/boss_info.json` | 当月会战存在 |
| 状态图乱码 | 检查 `resource/font` |
| Web 401 | Cookie 域名与 `public_host`、Nginx 同源 |
| 状态图慢 | 正常（PIL）；已异步渲染 |

## 升级与回滚

升级前备份：

- `resource/data/` 下 SQLite
- `setting_clanbattle.json`
- `data/` 账号与群库

数据库结构变更时执行模块内 migration（见发布说明）。
