# QQ【自动报刀帮助】正文源文件（一行一条，由 scripts/sync_help_text.py 生成 clanbattle/user_help.py）
# 以【 开头为有效行；空行与 # 注释在生成时忽略

【自动报刀帮助】查看本帮助
【出刀监控状态】群聊：查看监控与槽位（邮箱打码，全员）
【出刀监控】/【开启出刀监控】群聊：槽位1 开始监控（管理员+，需私聊绑定）
【出刀监控1/2/3】/【开启出刀监控1/2/3】群聊：指定槽位；切换槽位时先登录新账号再切监控（失败则保持原槽位）
【取消出刀监控】群聊：停止监控
【状态】群聊：查看当前会战进度（状态图；失败时回退文本）
【预约<boss>[周目N][:留言]】群聊：预约 Boss，例：预约1周目15：刀伤300w
【留言<boss>：<内容>】群聊：预约区留言（不触发周目@；Boss 击杀后自动清除）
【预约表】群聊：查看预约列表
【取消预约<boss>】群聊：取消自己在该 Boss 的预约/留言
【清空预约<boss>】群聊：管理，清空该 Boss 全部预约与留言
【申请出刀<boss>[b][:留言]】群聊：申请出刀，等同于【进<boss>...】；b 表示补偿刀申请
【取消申请】/【取消出刀】群聊：清空自己全部申请；【取消申请<boss>】清空指定 Boss
【清空申请<boss>】/【清空申请a】群聊：管理，清空申请+挂树（a=全王）
【清空未知申请<boss>】/【清空未知申请a】群聊：管理，清空未知玩家胶囊
【合刀/cal】群聊：两刀合刀补偿秒数计算
【开启合刀线提醒】/【关闭合刀线提醒】群聊：管理，D 面起报刀低于合刀线时 @ 其他申请者（默认开启）
【重新计算合刀线<1-5|a|A>】群聊：管理，重算合刀线（a/A=全部王）
【sl / sl[编号]?】群聊：记录或查询今日 SL（上报 sl 会清除申请出刀，不删预约）
【今日出刀】群聊：公会今日出刀次数统计图
【当期出刀】群聊：公会本期会战每日出刀次数统计图
【今日战报】群聊：自己名下所有账号今日出刀明细图
【当期战报】群聊：自己名下所有账号本期会战每日出刀明细图
【当前战报】群聊：本期会战累计战报
【我的战报[游戏id]】群聊：个人出刀详情，不带 id 时用绑定账号
【出刀详情<编号>】群聊：单条出刀详情
【修正出刀<编号><完整刀|尾刀|补偿>】群聊：修正刀型
【催刀】群聊：提醒未出满三刀成员
【挂树[boss][:留言]】群聊：挂树（须已有申请；可省略 boss）
【取消挂树】群聊：取消挂树，恢复为申请出刀状态
【掉刀 / 掉刀b[编号]】群聊：记录掉刀并扣点数
【清空出刀点数[编号]】群聊：强制用尽今日点数
【查1～查5】群聊：单 Boss 队列与血量状态图
【出刀记录<boss>[周目N|a[y|t]]】或【出刀记录<boss> <N>】群聊：指定周目或按日跨周目 Boss 出刀明细图（a=昨日/会战首日今日，at/ay 指定日；省略周目=监控当前周目）
【查树】群聊：查看挂树列表
【会战KPI】群聊：等效出刀 KPI 图
【kpi调整<游戏id><±数值>】群聊：管理，KPI 补正
【清空kpi / 删除kpi<游戏id>】群聊：KPI 补正管理
【启用肃正协议】群聊：清空本群全部出刀数据（危险）
【注册】私聊：注册 Web 登录账号（QQ 号 + 初始密码）
