# Web 会战面板

> 与 QQ 自动报刀 **共用同一数据库**；Web 操作 **不会** 向 QQ 群发送通知。

---

## 登录

1. **私聊** 机器人发送 `注册`，获取 QQ 号与初始密码  
2. 群聊或私聊发送 `面板` / `网页端登录`，按指引打开浏览器  
3. 使用 QQ 号 + 密码登录  

使用初始密码登录时，系统会提示尽快修改密码（可跳过）。

---

## 页面说明

| 页面 | 权限 | 功能 |
|------|------|------|
| **会战面板** | 全员 | Boss 血量、挑战队列、排名；管理员可删队列、开关监控 |
| **个人数据** | 全员 | 当期出刀记录、绑定/排序游戏账号 |
| **统计数据** | 全员 | 按日全员出刀表 |
| **管理运维** | KCR 管理员 | 成员代绑、监控账号、运维日志等 |

顶栏可选择已绑定的公会群（须先 `绑定本群公会` 或由管理员配置）。

---

## 与 QQ 的对应关系

| QQ | Web |
|----|-----|
| `状态` | 会战面板 + 状态图（同源 PNG 缓存） |
| `今日出刀` / `当期出刀` | 统计数据 |
| `今日战报` / `当期战报` | 个人数据 |
| `预约表` / 申请队列 | 会战面板队列区 |
| 管理员清空申请等 | 会战面板管理操作 |

**会战日**：每日 **05:00** 切换（与游戏一致）。

---

## 权限

- 普通用户：前三个页面  
- **KCR 管理员**（超管 + 委派 ≤5）：额外「管理运维」  
- QQ 群主/群管 **不等于** KCR 管理员  

---

## 常见问题

**Q：登录后看不到公会？**  
在目标群发送 `绑定本群公会`，或联系管理员在管理运维添加。

**Q：Web 能挂树/下树吗？**  
Web **不提供** 手动下树；击杀后自动下树逻辑与 QQ 一致。

**Q：数据多久刷新？**  
Boss 状态依赖群内 **出刀监控**（默认约 1 秒轮询）；面板通过 SSE 等方式推送更新。
