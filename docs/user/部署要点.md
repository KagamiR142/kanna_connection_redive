# 部署概要（自建机器人）

> 面向 **公会管理 / 运维**。完整步骤见 [安装与部署指南](../deploy/安装指南.md)。

## 你需要准备

| 组件 | 说明 |
|------|------|
| **HoshinoBot**（或兼容 NoneBot 的 PCR 机器人框架） | 加载本模块 |
| **QQ 协议端** | go-cqhttp、Lagrange 等，支持群聊/私聊/图片 |
| **一台常开服务器** | 会战期需 24h 运行监控 |

## 五步上线

### 1. 安装模块

将 `kanna_connection_redive` 放入：

```
HoshinoBot-master/hoshino/modules/kanna_connection_redive/
```

在 Hoshino 配置中启用该模块。

### 2. 配置文件

```bash
cd resource/data
cp setting_clanbattle.example.json setting_clanbattle.json
```

至少修改：

- `admin_qq` — 你的 QQ（超级管理员）
- `api.admin_key` — Web 管理 API 密钥
- `web_panel.public_host` — 访问 Web 面板用的域名或 IP

**勿将 `setting_clanbattle.json` 提交到 Git。**

### 3. 启动

1. 启动协议端  
2. 启动 Hoshino：`python run.py`  
3. 日志出现 `KCR Web API 已启动` 即成功  

### 4. 绑定与开监控

1. 管理员 **私聊** 机器人：`绑定账号帮助` → 按说明绑定监控号  
2. 在 **公会群** 发送：`出刀监控`  
3. 发送 `状态` 应收到会战状态图  

### 5. Web 面板（可选）

```bash
cd web && npm ci && npm run build
```

用 Nginx 反代 `/kanna_dependency` 到 API 端口，静态文件指向 `web/dist`。  
成员私聊 `注册` 后浏览器登录。

## 成员怎么用

无需部署知识，见 [五分钟上手](快速上手.md) 与 [自动报刀帮助](自动报刀.md)。

## 常见问题

| 现象 | 处理 |
|------|------|
| 状态图方框/乱码 | 检查 `resource/font` 是否完整 |
| `状态` 提示未开监控 | 群里先 `出刀监控` |
| Web 登录 401 | Cookie 域名与 `public_host`、反代同源 |
| 配置校验失败 | 对照 `setting_clanbattle.example.json` 补全字段 |

## 本地预览图片（无需 Bot）

开发者可在模块根目录运行：

```bash
python -m devtools.previews.status
```

详见 [devtools/说明.md](../../devtools/README.md)。
