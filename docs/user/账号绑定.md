# 账号与绑定说明

KCR 中有 **三类身份**，请勿混淆：

| 类型 | 用途 | 绑定方式 |
|------|------|----------|
| **监控账号** | 机器人登录游戏，轮询会战 API、自动报刀 | 私聊 `绑定账号1/2/3`（**管理员+**） |
| **成员游戏身份** | 战报、申请出刀、队列展示你的游戏名 | **Web「个人数据」**自选角色，或管理员在「管理运维」代绑（**不需要**私聊账号密码） |
| **Web 登录账号** | 浏览器登录会战面板 | 私聊 `注册` |

---

## 监控账号（出刀监控用）

**仅 KCR 管理员及以上** 可绑定。私聊发送 `绑定账号帮助` 查看完整说明。

### 绑定格式（私聊，加号表示空格）

```
绑定账号1 账号 密码          # B 服，槽位 1（默认监控槽）
绑定账号2 账号 密码          # 备用槽位 2
绑定账号3 账号 密码          # 备用槽位 3
渠绑定账号 login_id token    # 渠道服
台绑定账号 short_udid udid viewer_id   # 台服
```

- 过码失败可按帮助中的指令重试。
- 群聊 `出刀监控状态` 可查看槽位（邮箱已打码）。
- 私聊 `刷新会战元数据` 可更新当期 Boss 名称/头像（管理员+）。

### 与成员身份的关系

监控账号 **不参与** 你的个人战报归属；战报、申请队列中的「游戏名」来自 **成员游戏身份**（`user_account` 表）。

未绑定成员身份的用户仍可 `进1` 申请出刀，但战报类指令会提示先绑定。

---

## Web 成员身份（游戏 UID）

1. 私聊 `注册` → 获得 QQ 号 + 初始密码  
2. 登录 Web →「个人数据」→ 绑定游戏 UID（支持多账号、调整顺序）  
3. 群聊 `绑定本群公会` → 在 Web 顶栏选择该公会群

管理员可在 Web「管理运维」为任意 QQ **代绑 UID**（对方无需先注册；注册后即可使用）。

---

## KCR 管理员

| 角色 | 如何获得 | 能力概要 |
|------|----------|----------|
| 超级管理员 | `setting_clanbattle.json` 中的 `admin_qq` | 任命管理员、肃正协议等 |
| 委派管理员 | 超管私聊 `任命管理员 QQ号`（≤5 人） | 清空队列、关监控、Web 运维等 |

**QQ 群主/群管** 若未被任命为 KCR 管理员，权限与普通成员相同。

超管私聊指令：

- `任命管理员 QQ号`
- `撤销管理员 QQ号`
- `管理员列表`

---

## 账号编号（多账号用户）

绑定多个游戏账号时，按绑定顺序编号 **1～30**。

- 申请出刀可指定编号：`进2 2`（2 号账号打 2 王）
- 未指定时自动选用 **今日仍有出刀点数** 的第一个账号

---

## 安全提示

- 监控账号密码保存在部署机器本地配置/数据库中，请妥善保管服务器访问权限。
- 勿将 `setting_clanbattle.json` 或账号 JSON 提交到公开仓库。
