# 自动报刀帮助

> 对应 QQ 指令：**自动报刀帮助**  
> 机器人生成的帮助正文源文件：`clanbattle-help.qq.txt`（由 `scripts/sync_help_text.py` 同步到代码）。  
> 本文为用户可读版（表格排版）；指令列表与 QQ 帮助一致。

---

## 监控与状态

| 指令 | 说明 |
|------|------|
| `自动报刀帮助` | 查看本帮助 |
| `出刀监控状态` | 查看监控与槽位（邮箱打码，全员可见） |
| `出刀监控` / `开启出刀监控` | 槽位 1 开始监控（**管理员+**，需私聊绑定监控账号） |
| `出刀监控1` / `2` / `3` | 指定槽位；切换时先登录新账号，失败则保持原槽位 |
| `取消出刀监控` | 停止监控（**管理员+**） |
| `状态` | 会战进度状态图（未开监控时提示先开启） |
| `查1` … `查5` | 单个 Boss 队列与血量状态图 |

---

## 预约

| 指令 | 说明 |
|------|------|
| `预约<boss>[周目N][:留言]` | 预约 Boss，例：`预约1周目15：刀伤300w` |
| `留言<boss>：<内容>` | 预约区留言（Boss 击杀后自动清除） |
| `预约表` | 查看预约列表 |
| `取消预约<boss>` | 取消自己的预约/留言 |
| `清空预约<boss>` | **管理**：清空该 Boss 全部预约 |

**提示**：省略周目时预约的是 **当前周目 + 1**；须已开启出刀监控。

---

## 申请出刀与队列

| 指令 | 说明 |
|------|------|
| `申请出刀<boss>[b][:留言]` / `进<boss>…` | 申请出刀；`b` 表示补偿刀申请 |
| `取消申请` / `取消出刀` | 清空自己全部申请 |
| `取消申请<boss>` | 清空指定 Boss 的申请 |
| `清空申请<boss>` / `清空申请a` | **管理**：清空申请+挂树（`a`=全王） |
| `清空未知申请<boss>` / `a` | **管理**：清空未知玩家胶囊 |
| `挂树[boss][:留言]` | 挂树（须已有申请；可省略 boss） |
| `取消挂树` | 取消挂树，恢复为申请出刀状态 |
| `查树` | 查看挂树列表 |
| `sl` / `sl[编号]?` | 记录或查询今日 SL（上报 sl 会清除申请，不删预约） |
| `掉刀` / `掉刀b[编号]` | 记录掉整刀 / 掉补偿刀 |
| `清空出刀点数[编号]` | 强制用尽今日点数（修正平台高估时） |
| `合刀` / `cal` | 合刀补偿秒数计算，例：`合刀600 320 330`、`合刀576885 90` |

## 战报与统计

| 指令 | 说明 |
|------|------|
| `今日出刀` | 公会今日出刀次数统计图 |
| `当期出刀` | 公会本期会战每日出刀次数统计图 |
| `今日战报` | 自己名下账号今日出刀明细图 |
| `当期战报` | 自己名下账号本期会战每日明细图 |
| `当前战报` | 本期会战累计战报 |
| `我的战报[游戏id]` | 个人出刀详情 |
| `出刀详情<编号>` | 单条出刀详情 |
| `出刀记录<boss>[周目N\|a[y\|t]]` | 指定周目或按日跨周目某 Boss 全部出刀明细图 |
| `修正出刀<编号><完整刀\|尾刀\|补偿>` | 修正刀型记录 |
| `催刀` | 提醒未出满三刀成员 |

## KPI 与管理

| 指令 | 说明 |
|------|------|
| `会战KPI` | 等效出刀 KPI 图 |
| `kpi调整<游戏id><±数值>` | **管理**：KPI 补正 |
| `清空kpi` / `删除kpi<游戏id>` | **管理**：KPI 补正管理 |
| `启用肃正协议` | **危险**：清空本群全部出刀数据 |
| `开启合刀线提醒` / `关闭合刀线提醒` | **管理**：D 面报刀低于合刀线时 @ 其他申请者（默认开启） |
| `重新计算合刀线<1-5>` / `重新计算合刀线a` / `A` | **管理**：重算合刀线（`a`/`A` 为 1～5 王全部） |

D 面起，监控报刀在血量低于合刀线时可能附带合刀提醒前缀，并在消息末尾单独一行 `@`、一行合刀线数值。详见 [合刀线提醒](../design/合刀线提醒.md)。

## 权限说明（简要）

- **管理员+**：KCR 超级管理员或委派管理员（最多 5 人），**不是** QQ 群管。
- 清空预约/申请、关闭监控、KPI 调整等需管理员权限。
- 监控账号绑定、开启监控需管理员+。

详见 [账号与绑定](账号绑定.md)。

---

## 代发 @

部分指令可在 **末尾 @ 一位群成员**，视为该成员发送（如 `预约1@张三`）。  
`清空申请`、`清空出刀点数` **不支持** 代发。
