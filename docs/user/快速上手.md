# 五分钟上手

## 你会得到什么

- 群里自动推送出刀、击杀、队列变化
- 一张图看清五王血量与排队情况（【状态】）
- 预约下一周目、申请出刀、查战报
- 可选：浏览器打开会战面板（与 QQ 数据同步）

---

## 第一步：加好友

将机器人加为 QQ 好友。成员 **Web 注册** 在私聊完成；**监控账号** 仅管理员+私聊绑定（见 [账号绑定](账号绑定.md)）。

---

## 第二步：管理员开启监控（群聊）

由 **KCR 管理员**（非普通群管，见 [账号与绑定](账号绑定.md)）完成：

1. **私聊** 绑定监控账号（见 `绑定账号帮助`）
2. 在 **公会群** 发送：`出刀监控` 或 `开启出刀监控`
3. 发送 `出刀监控状态` 确认已开启

> 未开启监控时，【状态】、预约周目校验、出刀记录等会提示先开监控。

---

## 第三步：成员绑定游戏身份（Web）

成员出刀身份与监控账号 **不是一回事**：

1. **私聊** 发送：`注册` → 获得 Web 登录密码
2. 浏览器打开面板（群聊发 `面板` 可获链接指引）
3. 在「个人数据」绑定游戏 UID，或由管理员在「管理运维」代绑

也可在群聊发送 `绑定本群公会`，将本群加入你的 Web 公会列表（不要求已绑定 UID）。

---

## 常见问题

**Q：我发了指令没反应？**  
检查是否整句匹配、是否在正确群聊；部分指令仅管理员可用。

**Q：预约和申请有什么区别？**  
预约按 **QQ 用户**、针对 **下一周目**；申请按 **游戏账号**、针对 **当前可打的王**，会进入挑战队列。

**Q：Web 和 QQ 数据一致吗？**  
是，读写同一数据库；Boss 展示依赖监控每秒刷新。

**Q：掉刀 / SL 怎么用？**  
`sl` 记录今日 SL（会清除申请）；`掉刀` / `掉刀b` 记录掉整刀 / 掉补偿刀。
