# 游戏规则（平台须模拟）

> 代码实现：`knife_budget/`、`clanbattle/boss_snapshot.py`、`util/auto_boss.py`

---

## Boss 与周目

- 同时存在 5 个 Boss（1～5 王），各有独立血量与周目（Lap）。
- 会战 5 天，Boss 状态 **跨天累计**，不因换天重置。

### 周目生成（理解用）

击杀后计算 `M = min(K1+1, …, K5+1)`，对每个位置 i：若 `(Ki+1)−M ≤ 1` 则该位置存在可挑战 Boss，否则空缺。

**线上展示以游戏 API `top.boss_info[]` 为准**，不在本地 replay 推算五王（见 [platform.md](平台需求.md) §Boss 状态）。

### 会战阶段

| 阶段 | 周目 |
|------|------|
| B 面 | 1～6 |
| C 面 | 7～22 |
| D 面 | 23+ |

未击杀当前阶段全部 5 王时，**不会**生成下一阶段周目的 Boss（跨阶段门槛）。

## 每日挑战预算

- 每账号每天 **3.0 点**（3 刀），05:00 重置。
- **整刀**：未击杀消耗 1.0；击杀消耗 0.5 并产生 **1 个补偿刀**。
- **补偿刀**：固定消耗 0.5；击杀 **不再** 产生新补偿。
- 理论最多 6 次挑战，总消耗上限仍为 3.0 点。

### 补偿刀秒数

游戏内标准一刀 **90 秒**。合刀击杀公式（与 `合刀` 指令、`calc_comp_seconds` 一致）：

\[
s = \min\left(90,\ \left\lceil 110 - \frac{90R}{D} \right\rceil\right)
\]

- \(R\)：本条结算前 Boss **实际剩余血量**（账本，见 [knife-budget.md](刀型预算.md)）
- \(D\)：本条伤害

**收尾击杀**（\(D = R\)）：\(s = \min(90, \max(21, 110 - T))\)，\(T\) 为 `battle_time`。

合法区间 **[21, 90]**；90 秒为「满补」。

## 多账号同 Boss 结算

按 **结算完成顺序** 决定伤害生效，与进本先后无关。Boss 在某刀结算中归零后，后续未结算的进本 **撤销**（无伤害、不耗点）。

---

## SL 与掉刀

| 行为 | 效果 |
|------|------|
| SL（每日 1 次） | 结算前退出，无伤害、不耗点 |
| 掉刀 | 无伤害，仍耗对应刀型点数 |
| 掉刀b | 无伤害，耗 0.5 点（补偿刀） |
