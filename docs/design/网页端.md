# Web 端设计

> 前端：`web/`（Vue 3） · 后端：`webui/`  
> 用户说明：[user/网页端.md](../user/网页端.md) · API：[developer/API参考.md](../developer/API参考.md)

## 全局原则

| 项 | 规格 |
|----|------|
| 权限 | KCR 三档角色（超管 / 委派管理员 / 用户），与 QQ 群管无关 |
| Web 操作 | **不向 QQ 群发通知** |
| 挂树 | Web 不提供手动下树 |
| 会战日 | 05:00 切换 |
| Boss 数据 | 读监控 1 秒 top 镜像；**无**手动刷新 Boss |

---

## 信息架构

```
登录 / 改密
  ├── 会战面板（全员）
  ├── 个人数据（全员）
  ├── 统计数据（全员）
  └── 管理运维（管理员+）
```

顶栏：真实 OneBot 群名（`ClanBattleMember.group_name`），禁止固定占位「环奈连结」。

---

## 身份认证

| 步骤 | 行为 |
|------|------|
| 注册 | 私聊 `注册` → QQ 号 + 8 位随机初始密码 |
| 登录 | Cookie Session（建议 7 天） |
| 改密 | 8～20 位，字母数字，无符号 |

保留 `面板` 指令作登录指引；可与 URL 参数登录并存（产品选择不修改登录逻辑）。

---

## 会战面板

1. 顶栏：群名、监控徽章、排名  
2. 五王卡片：lap、HP 条、`fighter_num`、预约/申请/挂树计数  
3. 队列 Tab：预约（含目标周目）、申请、挂树  
4. 管理员：删队列项、开关监控（同 QQ 逻辑，不发群通知）

状态图：`GET /{gid}/status-image` + ETag；SSE `panel/stream` 推送更新。

---

## 个人数据

- 上：当期出刀记录（时间倒序，四态字段）  
- 下：UID 绑定、排序；可拉 `clan/info` 获取公会成员列表  

管理员可在「管理运维」批量代绑 `user_account`。

## QQ 联动

|---------|-------------|
| `绑定本群公会` | `ClanBattleMember` |
