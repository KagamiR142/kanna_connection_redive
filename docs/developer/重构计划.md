## 监控槽位合并示例

```python
MONITOR_SLOTS = (None, 3, 2, 1)  # None = 默认槽位 1

def register_monitor_handlers(sv):
    for slot in MONITOR_SLOTS:
        pattern = build_monitor_pattern(slot)
        handler = make_start_monitor_handler(slot)
        sv.on_rex(pattern)(decorators...)(handler)
```
