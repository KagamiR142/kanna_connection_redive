# 模块架构

## 总览

```
kanna_connection_redive/
├── clanbattle/          # 自动报刀核心（QQ 指令、监控、战报）
├── knife_budget/        # 四态刀型与每日预算
├── challenge/           # 挑战队列与进入信号
├── client/              # PCR 游戏 API 客户端
├── database/            # SQLModel 模型与 DAL
├── webui/               # FastAPI 后端
│   ├── api.py           # app 装配 + 启动
│   ├── routes/          # 按域拆分的路由（auth / panel / member / admin_ops）
│   ├── permissions.py   # Web 群内权限
│   ├── session.py       # Cookie 校验 + 主循环桥接
│   └── services/        # 业务服务
├── web/                 # Vue 3 前端
├── captcha/             # 过码辅助
├── util/                # 公共工具
│   ├── display/         # QQ / 游戏角色显示名
│   └── image/           # PNG 字体等渲染基础设施
├── resource/data/       # 配置与静态数据（规范路径）
└── docs/                # 本文档
```

**本计划维护范围**：`clanbattle/`、`knife_budget/`、`challenge/`、`database/`（会战相关）、`webui/`、`web/` 及共用 `util/`。

卫星模块（`fendao_test`、`jjckiller`、`support_query`）随仓库发布，但不在此架构演进范围内。

---

## 启动与注册

```
Hoshino 加载模块
  → __init__.py → ensure_config_or_exit()
  → 各子包 import → 注册 Service 处理器
  → login.py @on_startup → RBAC 初始化、Web 超管同步
  → clanbattle/__init__.py @on_startup → 连接池、schema 升级、Boss 元数据
  → webui/api.py @on_startup → uvicorn 线程
  → client/apiclient.py @on_startup → 版本/代理
```

### Hoshino Service 入口（会战相关）

| Service | 文件 | 职责 |
|---------|------|------|
| `自动报刀2` | `clanbattle/__init__.py` | 会战 QQ 指令 |
| `你只需要好好出刀` | `login.py` | 监控账号绑定、重登 |
| `环奈网页端管理` | `webui/__init__.py` | 挂载 FastAPI |

---

## 会战运行时数据流

```
群聊指令
  → command_parser / command_context
  → service 层（reserve、apply、status、report…）
  → database/dal (SQLite)
  → 回复 / PNG

出刀监控 (ClanBattle.loop_check)
  → login.query() → client (top + reload_detail_info)
  → knife_budget.service (结算四态)
  → challenge.service (队列信号)
  → RecordDao 持久化
  → 群推送 + status_cache 预渲染
```

### 共享状态

| 对象 | 位置 | 说明 |
|------|------|------|
| `clanbattle_info` | `clanbattle/registry.py` | 每群 `ClanBattle` 实例 |
| `client_cache` | `login.py` | 游戏客户端缓存 |
| `pcr_sqla` | `database/dal.py` | 异步 SQLite DAL |

## 分层约定（推荐）

新功能应遵循会战模块已采用的模式：

| 层 | 职责 | 示例 |
|----|------|------|
| Handler | 注册指令、鉴权、调用 service | `clanbattle/handlers/`（规划中） |
| Parser | 纯函数解析用户输入 | `command_parser.py` |
| Service | 业务逻辑 | `reserve_service.py`、`knife_budget/service.py` |
| DAL | 持久化 | `database/dal.py` |
| Response | 文案常量 | `response_messages.py` |

**避免**：在 handler 内直接写 SQL 或大段 PIL 绘图。

---

## Web 与 QQ 桥接

- FastAPI 跑在独立线程；访问游戏客户端须通过 `webui/util.py` → `call_in_main_loop()` 回到 nonebot 主循环。
- 权限：`webui/util.py` 结合 `rbac.py` 与 `GroupPriority`。
- 静态前端：`web/dist/` 由 Nginx 或 FastAPI 挂载。
