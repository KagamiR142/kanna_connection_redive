# 开源前敏感信息检查清单

推送 GitHub 前请确认：

## 必须排除（已在 `.gitignore`）

| 类型 | 路径模式 |
|------|----------|
| 游戏账号明文 | `data/account/**` |
| 群号 / 群数据 | `data/clanbattle/**` |
| 会战配置（含 admin_qq、密钥） | `resource/data/setting_clanbattle.json` |
| 所有日志 | `*.log`、`log/` |
| 预览 PNG 输出 | `devtools/output/` |
| 原始 API 留档 | `samples/`、`archive_output/` |

## 仓库内应使用的占位符

- QQ 号示例：`100000001`～`100000009`
- 群号示例：`1000000001`
- 配置：仅提交 `setting_clanbattle.example.json`

## 发布前命令

```bash
# 搜索疑似 QQ（8～11 位，需人工甄别游戏 ID）
rg '\b[1-9]\d{7,10}\b' --glob '!docs/backup/**' --glob '!*.lock'

python scripts/run_checks.py
```
