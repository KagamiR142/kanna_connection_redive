# 数据目录说明

会战模块存在两套路径，**行为上均有效**；开源仓库只保留模板与 `.gitkeep`，运行时数据不入库。

## 规范路径（推荐新部署）

| 路径 | 用途 |
|------|------|
| `resource/data/setting_clanbattle.json` | 主配置（从 `setting_clanbattle.example.json` 复制） |
| `resource/data/boss_info/` | Boss 元数据缓存 |
| `resource/data/` 下其它静态资源 | 字体、图片等 |

加载入口：`clanbattle_setting.py` → `ensure_config_or_exit()`。

## 运行时路径（`.gitignore`）

| 路径 | 用途 |
|------|------|
| `data/` | SQLite、`account/*.json`、群会战数据等 |
| `devtools/output/` | 预览脚本生成的 PNG |
| `*.log` | 日志 |

部分历史部署可能仍把配置放在模块外或旧路径；**本 refactor 不强制迁移**，新文档与示例均以 `resource/data/` + `data/` 为准。

## Web 相关

- API 监听：`clanbattle_setting` 中的 `api_host` / `api_port`（不再硬编码在业务路由中）
- 前端构建产物：`web/dist/`（可选同端口托管）
