## 代码对照清单

实现变更时建议同步检查：

1. `clanbattle/command_parser.py` — 解析是否与 [指令规格](commands/会战指令.md) §1 一致  
2. `clanbattle/response_messages.py` — 文案是否与 §3 一致  
3. `clanbattle/permissions.py` + `rbac.py` — 权限是否与 [permissions.md](权限模型.md) 一致  
4. `knife_budget/` — 算法是否与 [design/刀型预算.md](../design/刀型预算.md) 一致  
5. `webui/api.py` — 路由是否与 [api-reference.md](API参考.md) 一致  

## 测试与 CI

模块根目录：

```bash
python scripts/run_checks.py   # 文档 + pytest + ruff
pytest                         # 仅测试
```

- `tests/` — 帮助文本、文档链接  
- `clanbattle/test_*.py` — 指令解析、申请展示  
- `knife_budget/test_*.py` — 刀型结算  

GitHub Actions：`.github/workflows/ci.yml`
